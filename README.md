## 📁 Проекты

### 1. 📚 Учебный проект — «Система учета и управления персоналом»

**Контекст:** Курс «Бизнес-аналитика в сфере разработки ПО» (IT-Academy, 2025). Командная работа над дипломным проектом.

**Задача:** Разработать полный набор аналитических артефактов для модуля «Менеджер» системы управления персоналом IT-компании (150+ сотрудников).

**Моя роль:** Бизнес-аналитик (команда из 4 человек). Осуществлял сбор и формализацию требований, мониторинг изменений в смежных модулях, инициировал совместные митинги для разрешения коллизий.

**Результат:**
- 2 документа (Vision & Scope, SRS)
- 5 диаграмм (UML, BPMN, Activity, User Flow, Visual Representation)
- Бизнес-цели с измеримыми KPI (сокращение времени согласования на 20%, обработки фидбеков на 30%, отчетности на 50%)

[👉 Подробнее](01-academic-project/README.md)
