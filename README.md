## 📁 Проекты

### 1. Учебный проект — «Система учета и управления персоналом»

**Контекст:** Дипломный проект по курсу «Бизнес-аналитика в сфере разработки ПО» (IT-Academy, 2025). Командная работа над модулем «Менеджер» системы управления персоналом для IT-компании (150+ сотрудников).

**Задача:** Разработать полный набор аналитических артефактов для модуля «Менеджер» — связующего звена между четырьмя независимыми модулями системы («Личная карточка», «Овертаймы», «Фидбеки», «Проекты»). Каждый модуль разрабатывала отдельная команда бизнес-аналитиков. Наша команда отвечала за интеграцию данных из всех модулей в единый управленческий интерфейс.

**Моя роль:** Бизнес-аналитик (команда из 4 человек). Координация с другими командами, разрешение коллизий требований, инициация совместных митингов.

**Артефакты:**
- 2 документа: Vision and Scope, Software Requirements Specification
- 5 диаграмм: Use Case, BPMN, Activity, User Flow, System Visual Representation

[Подробнее](01-academic-project/README.md)

**Артефакты:**
