# 🤖 Booking Bot

Telegram-бот для бронирования мест в заведениях.

---

## О проекте

**Задача:** автоматизировать бронирование мест в кафе, ресторанах и коворкингах — убрать звонки и ручную координацию.

**Моя роль:** бизнес-аналитик (сбор требований, документация, моделирование).

**Результат:** комплект аналитических артефактов для передачи в разработку.
