# 📚 Система учета и управления персоналом — Модуль «Менеджер»

Дипломный проект по курсу «Бизнес-аналитика в сфере разработки ПО» (IT-Academy, 2025).  
Система учета и управления персоналом для условной IT-компании (150+ сотрудников).

---

## О проекте

**Задача:** разработать модуль «Менеджер» — автоматизировать учёт проектов, овертаймов, фидбеков и согласование графиков.

**Контекст:** модуль «Менеджер» — **связующее звено** между четырьмя независимыми модулями системы («Личная карточка», «Овертаймы», «Фидбеки», «Проекты»). Каждый модуль разрабатывала отдельная команда бизнес-аналитиков. Наша команда отвечала за интеграцию данных из всех модулей в единый управленческий интерфейс. Любое изменение в требованиях смежных модулей требовало оперативной корректировки в нашем модуле — это обеспечило навыки кросс-командного взаимодействия и управления зависимостями.

**Моя роль:** бизнес-аналитик (команда из 4 человек). Координация с другими командами, разрешение коллизий требований, инициация совместных митингов.

**Результат:** полный комплект аналитических артефактов для передачи в разработку.
